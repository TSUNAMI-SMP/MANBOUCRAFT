# ManbouCraft

Paper **1.21.11** / Java **21** 向けのマンボウサバイバルプラグイン。
採掘・レシピはバニラのまま、56種類の特殊死亡（55種類の確率死と落下即死）を追加します。コマンドとGUIはありません。

## 導入

[ManbouCraft-0.2.0.jar をダウンロード](https://github.com/TSUNAMI-SMP/MANBOUCRAFT/raw/refs/heads/main/dist/ManbouCraft-0.2.0.jar)

1. サーバーを停止し、ワールドとプラグインデータをバックアップしてください。
2. build/libs/ManbouCraft-0.2.0.jar を Paper 1.21.11 の plugins/ に入れて起動します。
3. 生成された plugins/ManbouCraft/config.yml を編集して再起動します。
4. required-grave-plugin に墓プラグインの plugin.yml 内の name を設定してください。設定したプラグインが無効なら特殊死亡は停止します。空欄では墓プラグインの存在確認を行いません。

ManbouCraft は墓を実装せず、アイテム・経験値・死亡ドロップ・keepInventory を変更しません。
墓プラグインがない場合、通常の死亡ドロップになります。墓の保管、座標通知、本人限定回収、
再起動後の保持は採用した墓プラグインで設定してください。個別の墓プラグインとの併用試験は未実施です。

## 難易度変更（0.2.0）

- 避けられる危険は高確率：水面衝突100%、生魚の寄生虫80%、腐った肉95%、燃焼・トゲ95%。
- 避けにくい日常行動は低確率：クラフト・持ち替え0.5%、パン・焼いた食べ物・牛乳1%。
- ワールドにいるだけの死は低確率：孤独・ニワトリ・ネコ0.1%、ネザー・エンド0.15%。
- イベント型の抽選間隔は30秒から8秒、環境型は60秒から12秒へ短縮。
- リスポーン・ログイン保護は60秒から10秒へ短縮。落下即死は保護中も対象です。
- 水面衝突は3ブロック以上で100%、寄生虫は生魚を食べて5〜15秒後に80%。
- 走行距離の条件は300から80ブロック、雨の持続は60から10秒へ短縮。
- 新たに25種類を追加しました。

古い config.yml は初回起動時に自動移行します。元ファイルは config-backups/ に保存します。
旧版の初期値と一致する確率・間隔・保護時間を新しいバランスの値に置き換え、新しい死因の項目を追加します。
初期値と異なる独自の数値、enabled: false、カスタムメッセージ、墓プラグイン名は維持します。
旧初期値と同じ値を意図して設定していた場合も移行対象なので、必要に応じて移行後に戻してください。
config-version: 2 を記録し、2回目以降の起動では移行を繰り返しません。
YAML が壊れている場合は原本を変更せず、プラグインを無効にします。

## 落下即死（0.1.1以降）

最終的な落下ダメージが少しでも正数なら確率100%で死亡します。1ダメージ（ハート半分）も、1未満も対象です。
落下イベントをキャンセルした場合や最終ダメージ0の場合は対象外。Creative / Spectator も対象外です。
この落下即死はリスポーン保護と確率抽選を迂回します。墓プラグインの必須チェックは維持します。
死亡ログは「○○はたった一段の油断で骨も心も折れた。」、統計IDは fall_fragility です。
fatal-fall-damage: false で無効化、fatal-fall-message で文章を変更できます。
以前の config.yml に項目がなくても既定で有効です。JAR を差し替え、サーバーを再起動してください。

## 表示と保護

- 死亡画面の死因欄に「突然の死」の3行装飾と死因を表示します。Minecraft 自体のタイトルやボタンは変更しません。
- 特殊死亡ログは黄色の名前、白い「は」、死因ごとのカラフルな文章です。接頭辞や重複通知を追加しません。
- 通常死のチャットメッセージはそのままです。他プラグインが後から上書きすると、その表示が優先される場合があります。
- ログイン・リスポーン・有効化後の10秒間は特殊死亡を保護します。バニラのダメージは防ぎません。
- Survival / Adventure のみ対象。特殊死亡はトーテムを消費せず、復活効果を迂回します。
- 死亡が他プラグインでキャンセルされた場合は統計に加算せず、10秒間再試行を抑制します。

## 設定

config.yml で死因ごとの enabled / probability / interval-seconds / message を変更できます。
確率は0〜1、判定間隔は1〜86400秒。確率0では発動せず、1では条件成立時に必ず発動します。
失敗した抽選もその死因の判定間隔を消費します。他の死因の抽選間隔は独立しています。
環境条件は1秒ごとに観測しますが、抽選は既定で12秒に1回です。
message には「名前は」を含めず、その後の文を指定してください。
message-color: auto では死因ごとに色を選びます。aqua などで固定色も指定できます。
設定変更には再起動が必要です。

## モブ制御

オーバーワールドでは敵対種の全スポーン理由（自然・スポナー・卵・コマンド等）を抑止します。
既存の敵対種も有効化時とチャンク読み込み時に削除し、敵対種への変化とポータル・テレポートによる移入も抑止します。
ネザー・エンドは変更しません。エンダーマン・ピグリン・ゾンビピグリンなどの中立種は維持します。
クモは敵対種として扱います。suppress-overworld-hostiles: false でこの制御を無効にできます。

## 保存

- statistics.yml: UUID別の全死亡数、特殊死亡数、死因別回数（図鑑の元データ）。死亡イベント成立時だけ更新します。
- rule-state.yml: 寄生虫の残り時間と設置したダイヤ鉱石の座標。退出・正常終了時、および60秒ごとに保存します。
- ファイルは一時ファイルを経由して置き換えます。異常終了やストレージ故障による完全な保全は保証しません。
- YAML が壊れている場合はプラグインを無効化し、壊れたファイルを上書きしません。

## 開発と検証

JDK 21 を使用して以下を実行します。

    ./gradlew build

成果物は build/libs/ManbouCraft-0.2.0.jar、テスト結果は build/reports/tests/test/index.html。
Gradle Wrapper 8.14.3 は配布ファイルのSHA-256を固定しています。
自動テストは確率・保護時間・有効化・死亡メッセージ・死亡キャンセル・統計・ドロップ不変更・モブ制御を対象にしています。
クライアントによる表示確認、56条件それぞれの実機再現、採用済み他プラグインとの併用は別途必要です。


## 対策できる死と低確率の死

恐怖・ストレス系は **しゃがんでいる間、抽選を完全に止めます**。
ダイヤを掘る、プレイヤー・村人との接近、暗所や高所、釣り針・鐘への驚きなどは落ち着いて行動すれば防げます。
下の一覧の「しゃがみで防止」列を確認してください。しゃがみ始めた際のこむら返りは0.1%だけ残ります。

しゃがんでも落下・水面への激突・炎・トゲ・危険な食事は防げません。
落下を避ける、火やサボテンから離れる、生魚・腐肉・怪しいシチューを食べない、屋根の下で雨を避ける、
松明で暗所を照らす、深い水を避ける、といった具体的な対策を基本にしてください。
通常の食事・クラフト・持ち替えなど、避けにくいギャグ死は0.1〜3%に抑えています。
calm-protection-while-sneaking: false にすると、しゃがみによるストレス保護を無効化できます。

## 56種類の条件と初期確率

イベント型は条件が成立した出来事ごとに抽選し、失敗後も8秒は同じ死因を抽選しません。
環境型は該当する間12秒ごとに抽選します。特記した持続条件以外は最初の観測時にも抽選します。
確率は条件1回の抽選に対する値です。複数の条件が重なると全体の死亡率は高くなります。
しゃがみ対策により止まった判定は抽選間隔を消費しません。
