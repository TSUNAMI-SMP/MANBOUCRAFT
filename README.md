# ManbouCraft

Paper **1.21.11** / Java **21** 向けのマンボウサバイバルプラグイン。
採掘・レシピはバニラのまま、30種類の特殊死亡を追加します。コマンドとGUIはありません。

## 導入

[ManbouCraft-0.1.0.jar をダウンロード](https://github.com/TSUNAMI-SMP/MANBOUCRAFT/raw/refs/heads/main/dist/ManbouCraft-0.1.0.jar)

1. サーバーを停止し、ワールドとプラグインデータをバックアップしてください。
2. build/libs/ManbouCraft-0.1.0.jar を Paper 1.21.11 の plugins/ に入れて起動します。
3. 生成された plugins/ManbouCraft/config.yml を編集して再起動します。
4. required-grave-plugin に墓プラグインの plugin.yml 内の name を設定してください。設定したプラグインが無効なら特殊死亡は停止します。空欄では墓プラグインの存在確認を行いません。

ManbouCraft は墓を実装せず、アイテム・経験値・死亡ドロップ・keepInventory を変更しません。
墓プラグインがない場合、通常の死亡ドロップになります。墓の保管、座標通知、本人限定回収、
再起動後の保持は採用した墓プラグインで設定してください。個別の墓プラグインとの併用試験は未実施です。

## 表示と保護

- 死亡画面の死因欄に「突然の死」の3行装飾と死因を表示します。Minecraft 自体のタイトルやボタンは変更しません。
- 特殊死亡ログは黄色の名前、白い「は」、死因ごとのカラフルな文章です。接頭辞や重複通知を追加しません。
- 通常死のチャットメッセージはそのままです。他プラグインが後から上書きすると、その表示が優先される場合があります。
- ログイン・リスポーン・有効化後の60秒間は特殊死亡を保護します。バニラのダメージは防ぎません。
- Survival / Adventure のみ対象。特殊死亡はトーテムを消費せず、復活効果を迂回します。
- 死亡が他プラグインでキャンセルされた場合は統計に加算せず、10秒間再試行を抑制します。

## 設定

config.yml で死因ごとの enabled / probability / interval-seconds / message を変更できます。
確率は0〜1、判定間隔は1〜86400秒。確率0では発動せず、1では条件成立時に必ず発動します。
失敗した抽選もその死因の判定間隔を消費します。他の死因の抽選間隔は独立しています。
環境条件は1秒ごとに観測しますが、抽選は既定で60秒に1回です。
message には「名前は」を含めず、その後の文を指定してください。
message-color: auto では死因ごとに色を選びます。aqua などで固定色も指定できます。
設定変更には再起動が必要です。

## モブ制御

オーバーワールドでは敵対種の全スポーン理由（自然・スポナー・卵・コマンド等）を抑止します。
既存の敵対種も有効化時とチャンク読み込み時に削除し、敵対種への変化とポータル・テレポートによる移入も抑止します。
ネザー・エンドは変更しません。エンダーマン・ピグリン・ゾンビピグリンなどの中立種は維持します。
クモは敵対種として扱います。suppress-overworld-hostiles: false でこの制御を無効にできます。

## 保存

- statistics.yml: UUID別の全死亡数、特殊死亡数、死因別回数（図鑑の元データ）。死亡イベント成立時だけ更新します。
- rule-state.yml: 寄生虫の残り時間と設置したダイヤ鉱石の座標。退出・正常終了時、および60秒ごとに保存します。
- ファイルは一時ファイルを経由して置き換えます。異常終了やストレージ故障による完全な保全は保証しません。
- YAML が壊れている場合はプラグインを無効化し、壊れたファイルを上書きしません。

## 開発と検証

JDK 21 を使用して以下を実行します。

    ./gradlew build

成果物は build/libs/ManbouCraft-0.1.0.jar、テスト結果は build/reports/tests/test/index.html。
Gradle Wrapper 8.14.3 は配布ファイルのSHA-256を固定しています。
自動テストは確率・保護時間・有効化・死亡メッセージ・死亡キャンセル・統計・ドロップ不変更・モブ制御を対象にしています。
クライアントによる表示確認、30条件それぞれの実機再現、採用済み他プラグインとの併用は別途必要です。

## 30種類の条件と初期確率

イベント型は出来事ごとに抽選し、失敗後も既定30秒は同じ死因を抽選しません。
環境型は該当する間、既定60秒ごとに抽選します。特記した持続条件以外は最初の観測時にも抽選します。

| ID | 条件 | 初期確率 |
|---|---|---:|
| water_impact | 6ブロック以上落下して水に入る。飛行・滑空・乗車中は除外 | 20% |
| parasite | 生のタラ・サケを食べて30〜90秒後。退出中・保護中は残り時間を停止 | 5% |
| fishing_shock | 8ブロック以内で他プレイヤーが釣り針を投げる | 5% |
| temperature_shock | 気温0.2未満の環境とそれ以外を行き来する | 5% |
| diamond_joy | ダイヤ鉱石を採掘。導入後にプレイヤーが設置した鉱石は除外 | 5% |
| bed_neck | ベッドに入ることに成功する | 3% |
| ender_pearl | エンダーパールでテレポートする | 10% |
| sprinting | 徒歩のスプリント距離が累計300ブロックに達する | 5% |
| egg_shock | 卵が当たる | 5% |
| snowball_shock | 雪玉が当たる | 5% |
| door_shock | ドアを右クリックする | 2% |
| chest_anxiety | チェストを開く | 2% |
| tool_break | 道具が壊れる | 10% |
| flower_emotion | 小さな花を摘む | 2% |
| bell_shock | 10ブロック以内で鐘が鳴る | 5% |
| boat_sickness | ボートに乗る | 3% |
| rain_stress | オーバーワールドの屋外で雨に60秒以上濡れる | 1% |
| thunder_fear | 雷雨の屋外にいる | 2% |
| player_contact | 仲間との距離1.2ブロック未満が2秒続く | 2% |
| villager_stare | 4ブロック以内の村人が自分を向き、見通しがある状態が5秒続く | 2% |
| heavy_bag | 通常インベントリ36枠のうち32枠以上が埋まる | 1% |
| dark_fear | 明るさ3以下の場所にいる | 1% |
| height_fear | 高さ150以上の屋外にいる | 1% |
| deep_water | 水中にいて3ブロック下も水である | 2% |
| lava_fear | 周囲1ブロックに溶岩がある | 2% |
| loneliness | 同じワールドの32ブロック以内に対象ゲームモードの仲間がいない | 0.5% |
| hunger_despair | 満腹度が6以下 | 1% |
| nether_panic | ネザーにいる | 1% |
| end_anxiety | エンドにいる | 1% |
| chicken_stare | 3ブロック以内にニワトリがいる（視線判定なし） | 1% |

寄生虫は1人1件まで予約し、待ち時間終了時に抽選します。死亡すると予約を解除します。
水面衝突の確率は初期版では落下距離によらず固定です。
